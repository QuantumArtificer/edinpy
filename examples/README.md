# EDinPy examples

The examples are split by particle statistics.

## Fermions

```bash
python examples/fermion/hubbard_dimer.py
python examples/fermion/hubbard_chain.py
python examples/fermion/extended_hubbard_chain.py
python examples/fermion/spin_exchange.py
python examples/fermion/flux_threaded_ring.py
```

## Bosons

```bash
python examples/boson/bose_hubbard_dimer.py
python examples/boson/bose_hubbard_chain.py
python examples/boson/spin_exchange.py
```

The documentation contains the corresponding equations, figures, and reference comparisons.
