# User guide

The user guide follows the order of a typical fermionic exact-diagonalization calculation. Each section uses executable examples and printed output so that the symbolic front end, basis conventions, matrix construction, eigensolver behavior, and observable algebra can be inspected directly. Exact signatures and parameter lists live in the {doc}`../reference/index`.
