API reference
=============

The public namespaces are :mod:`edinpy.fermion` and :mod:`edinpy.boson`.
Classes shared by both namespaces are documented once under Core API.
Statistics-specific mode spaces, Fock bases, sectors, and primitive operators
are documented under Fermion API and Boson API.
