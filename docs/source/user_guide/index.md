# User guide

Exact diagonalization replaces an interacting many-body problem by an exact eigenproblem in a finite Fock-space sector. The essential choices are physical: the local degrees of freedom, the conserved quantum numbers used to restrict the Hilbert space, the Hamiltonian, the observables, and the finite-size sequence needed for the question being studied.

Fixed-particle-number sectors, eigenvalue problems, and expectation values have the same mathematical role for fermions and bosons. Their local occupation rules and creation-annihilation algebra are treated separately where the statistics differ.
